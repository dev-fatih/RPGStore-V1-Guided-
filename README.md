# RPG Store Console App
A personal learning project developed to improve my OOP(Object Oriented Programming) skills. It's currently a console based program that allows player to create a user, buy items, see their inventory and balance.

#Important Note: This project is not currently seamless. As you may seen there's some problems with it like when you close the app your character is deleted from ram, there's no button for selling items etc. This project is just a learning project as i stated in "About" of project.
#Important Note 2: I want to state that this project is guided too. I've not copied anything and wrote everything by myself but i used internet and tools to learn how to code this.

  ## 🚀 Project Roadmap & Future Versions
  This project serves as a sandbox for my programming journey. It will continuously be updated as i learn new technologies:

- [x] **V1 (Current):** Core mechanics using OOP principles (Classes, Interfaces, Encapsulation, Lists, Constructors).
- [ ] **V2:** Refactoring code using LINQ and advanced C# features for better logic and search operations.
- [ ] **V3:** Database integration (SQL & Entity Framework Core) to permanently store user data and item catalogs.
- [ ] **V4:** Moving away from the console to a graphical user interface (GUI).
- [ ] **V5:** Implementing a turn-based fighting system and potentially moving the backend to a RESTful API.

## 🛠️ Technologies & Concepts Used (V1)
* **Language:** C#
* **Framework:** .NET (Console App)
* **Core Concepts:** 
  * Interfaces (`IItem`) for polymorphism
  * Encapsulation (`get/set` properties)
  * Collection Management (`List<T>`)
  * Basic Lambda expressions and indexing

 ## 💡 How to Run
1. Clone the repository to your local machine.
2. Open the `.sln` file using Visual Studio.
3. Run the project (F5) and use the numeric keys to navigate the store menu.
